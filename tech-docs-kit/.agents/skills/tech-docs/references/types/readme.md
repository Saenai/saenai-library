# README

The entry point to a repository or directory. Answers: what is this, how do I use it, where do I go next. Short; detail lives in the documents it links to.

File: `README.md` in the directory it describes.

Example: [sample-repo README](../../examples/sample-repo/README.md)

## Skeleton

```markdown
# {{Name}}

{{One paragraph: what this is and who it is for.}}

## Quick start
## Usage
## Layout
## Related documents
```

Leave out `Layout` when the directory structure is obvious, and `Related documents` when there are none.

## Sections

**Quick start.** The shortest path to a working result: prerequisites, commands in a code block, and what success looks like.

**Usage.** Common tasks, each as a short subsection or a row in a table of commands. Link to a reference for the full option list.

**Layout.** Table: path, contents. Only the top-level entries that matter.

**Related documents.** Links to designs, runbooks and ADRs, with one line each on when to read them.

## Leave out

Badges and boilerplate that tell this team nothing, change logs, and long design explanations.
